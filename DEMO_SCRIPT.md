# 🎬 SmartStudy Quiz Maker — 2-Minute Demo Video Script

> Use this script while screen recording. Read the **Talk** lines aloud and perform the **Action** steps on screen.

---

## Timing Breakdown

| Section | Time | What to Show |
|---|---|---|
| Intro | 0:00–0:15 | You + project overview |
| Input & Generate | 0:15–0:45 | Paste notes, click Generate Quiz |
| Answer Questions | 0:45–1:30 | Click answers, watch feedback |
| Score & Reset | 1:30–1:45 | Final score, Try Again |
| Tech Stack | 1:45–2:00 | Code overview, wrap up |

---

## Section 1: Introduction (0:00–0:15)

**[On screen: SmartStudy Quiz Maker at `http://localhost:3000`]**

**Talk:**
> "Hi, I'm [Your Name], and this is SmartStudy Quiz Maker — my project for the Global AI Hackathon. It's an AI-powered web app that turns any study notes into an instant interactive quiz. Students paste their notes, click one button, and get five multiple-choice questions generated by Google Gemini AI — with instant feedback and scoring."

**Action:**
- Show the homepage with the purple gradient, heading, and textarea
- Briefly gesture toward the input area and Generate Quiz button

---

## Section 2: Paste Notes & Generate Quiz (0:15–0:45)

**[On screen: Notes input area]**

**Talk:**
> "Let me show you how it works. I'll paste some study notes about cellular respiration — this is real content a student might have."

**Action:**
1. Click into the textarea
2. Paste this text *(or your own notes)*:

```
The mitochondria is the powerhouse of the cell. It converts glucose and oxygen into ATP through cellular respiration. ATP is the energy currency that powers all cellular activities. The process has three stages: glycolysis breaks down glucose in the cytoplasm, the Krebs cycle occurs in the mitochondrial matrix, and the electron transport chain happens along the inner membrane.
```

**Talk:**
> "Now I click Generate Quiz. The app sends these notes to Google Gemini, which reads them and creates five understanding-based questions — not just memorization, but concepts."

**Action:**
3. Click **Generate Quiz**
4. Show the spinner animation on the button
5. Wait for the quiz to appear (5–15 seconds)

**Talk:**
> "And here are five questions generated live by AI — each with four options and one correct answer."

---

## Section 3: Answer Questions with Instant Feedback (0:45–1:30)

**[On screen: First quiz question visible]**

**Talk:**
> "Now I'll answer the questions. Watch what happens when I click."

**Action:**
1. **Question 1** — Click an answer
   - If correct: green highlight appears instantly
   - If wrong: red highlight on your choice, green on correct answer

**Talk:**
> "Instant feedback — green means correct, red means wrong, and the right answer is revealed immediately. I can't change my answer, just like a real quiz."

**Action:**
2. **Question 2** — Click a wrong answer on purpose
   - Show both red (your choice) and green (correct) simultaneously

**Talk:**
> "See? I got this one wrong, and the app shows me the correct answer right away. This helps students learn from mistakes immediately."

**Action:**
3. **Questions 3–5** — Click answers (mix of correct and wrong for variety)

---

## Section 4: Final Score & Try Again (1:30–1:45)

**[On screen: All questions answered, score container appears]**

**Talk:**
> "After all five questions, my score appears — I got three out of five, which is sixty percent. The app tracks both correct count and percentage."

**Action:**
- Show the score box clearly: "You scored 3/5 (60%)"

**Talk:**
> "If I want to study something else, I click Try Again."

**Action:**
1. Click **Try Again**

**Talk:**
> "The quiz disappears, the notes are cleared, and I'm back to the start — ready to paste new notes and generate a brand new quiz."

**Action:**
- Show the clean homepage with empty textarea

---

## Section 5: Tech Stack & Wrap Up (1:45–2:00)

**[On screen: VS Code or terminal showing project files]**

**Talk:**
> "Behind the scenes, SmartStudy uses a simple but secure architecture. The frontend is vanilla HTML, CSS, and JavaScript — no frameworks needed. The backend is Node.js with Express. When you click Generate Quiz, the notes go to our server, which calls the Google Gemini API using a secure API key stored in environment variables — never exposed to the browser or GitHub. The AI returns structured JSON, which we validate and send to the frontend. We even built automatic fallback — if one Gemini model is busy, we try another instantly."

**Action:**
- Briefly scroll through `server.js` to show the Gemini call
- Show `.env.example` to demonstrate the placeholder pattern
- Show `.gitignore` excluding `.env`

**Talk:**
> "That's SmartStudy Quiz Maker — AI-powered learning, built for students, built for the Global AI Hackathon. Thank you!"

**Action:**
- End screen: Show the GitHub repo URL or project name
- Smile, wave, or give a thumbs up

## 🎥 Recording Tips

| Tip | Why |
|---|---|
| Use **Chrome or Edge** in full-screen | Cleanest look |
| Zoom browser to **125–150%** | Easier to read on video |
| Record at **1920×1080** minimum | Professional quality |
| Speak clearly, not too fast | Judges may not be native speakers |
| If Gemini is slow (~15s), keep talking | Explain what the AI is doing |
| Show your face in a corner (optional) | Personal connection with judges |
| Add captions if possible | Accessibility bonus |

## 📝 Backup Notes (If Something Goes Wrong)

**If Gemini is very slow:**
> "Gemini is thinking — this usually takes about 10 seconds. The AI is reading the notes, understanding the concepts, and crafting questions that test comprehension, not just memorization."

**If you get an error:**
> "If the API is experiencing high demand, our fallback system automatically tries another model. But for this demo, everything is working smoothly."

**If you want shorter notes:**
Use this 1-sentence version:
> "Water evaporates from rivers, condenses into clouds, then precipitates as rain."
